# Calm mode and motion policy

Animation is encouraged, but WCAG 2.2 AA and speed constrain it. All non-essential motion is progressive enhancement: it runs on transform and opacity only, never flashes, is never required to reach content, and is disabled by Calm mode (on by default under `prefers-reduced-motion`). There are no custom cursors and no scroll-jacking, and every toy has a keyboard alternative.
